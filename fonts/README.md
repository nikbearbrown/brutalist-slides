# Fonts

These faces are here so `./bs offline` can put them inside a deck for a room with no internet. All three are under the SIL Open Font License 1.1; each licence file is beside its fonts.

| Face | Files | Licence |
|---|---|---|
| Lato | `Lato-Regular.ttf`, `Lato-Bold.ttf` | `Lato-OFL.txt` |
| EB Garamond | `EBGaramond-Regular.ttf`, `EBGaramond-Medium.ttf`, `EBGaramond-Italic.ttf` | `EBGaramond-OFL.txt` |
| JetBrains Mono | `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf` | `JetBrainsMono-OFL.txt` |

Online, decks load the same faces from Google Fonts. To add a face for your own style, put its files and its licence here and list them in the style's `style.json`.
