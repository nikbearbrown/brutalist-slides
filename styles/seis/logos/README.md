# SEIS logos

The files are not in the repository. They are Northeastern's and the department's marks.

| File here | What it is | Where it comes from |
|---|---|---|
| `seis-logo.png` | The SEIS lockup: the N with "Northeastern University / Software Engineering and Information Systems". 463 x 149, transparent | The SEIS department |
| `monogram-red.svg`, `monogram-white.svg` | The Northeastern monogram | The Brand Center's Primary Marks set |

The lockup is a low-resolution raster. Show it at 463 x 149 or smaller, on white. Ask the department for a vector file before using it larger. Units may not make their own marks.

Without the files the logo slot stays empty. The unit's name still prints at the foot of the title and closing slides.
