# Northeastern logos

The files are not in the repository. Northeastern's marks are trademarks, and using them needs the right to use them: staff, faculty and students doing university work. The colours in this style do not grant that.

To use them, download the Primary Marks set from the Northeastern Brand Center (brand.northeastern.edu, Brand Assets) and put these four RGB SVG files here with these names:

| File here | From the Primary Marks set |
|---|---|
| `monogram-red.svg` | Monogram, red |
| `monogram-white.svg` | Monogram, white |
| `primary-logo-red-black.svg` | Primary logo, red and black |
| `primary-logo-red-white.svg` | Primary logo, red and white |

Rules, from the Brand Center: never redraw or recolour a mark; clear space equal to the height of the N on every side; the N never smaller than 12 px; never red on red; never on a photograph without a scrim. In a deck the logo goes on the title and closing slides only.

Without the files the logo slot stays empty and the deck is otherwise the same.
